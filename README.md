## 🛠️ What I Do

- **From design to a live site:** I build the design faithfully and set up a CMS the team can edit on its own.
- **Astro & Sanity:** Sites with a headless CMS: multiple languages, a content structure built around the project and editing with a live preview.
- **A/B tests:** On Webflow and Astro: I build the variants, split the traffic and measure the results. The version that converts better stays on the site.
- **Integrations:** Newsletters, CRMs, job openings from recruiting tools and forms that feed Slack or spreadsheets, through Zapier or custom code against their APIs.
- **Performance:** I measure PageSpeed and Core Web Vitals, then remove whatever slows the site down.
- **Analytics:** GA4, Tag Manager and Search Console, so you can see where traffic comes from and what limits its growth.

## 🧰 Tools I Build

- **[Audyt](https://sergiuszrozycki.com/en/projects/audyt/)** checks the speed, WCAG 2.2 AA accessibility, SEO and UX/UI of a site, with a report online and as a PDF.
- **[Linkrot](https://sergiuszrozycki.com/en/projects/linkrot/)** finds the broken links before Google does: every page in the sitemap and every link in the content.
- **[figlift](https://sergiuszrozycki.com/en/projects/figlift/)** turns a link to a Figma file into an Astro site with its content in Sanity.
